# 合成样本约定

仓库是公开的。进入 git 的物流样例必须是可辨识的合成数据，不能是真实运单、取件码、收件人、电话或具体住址。

## 真实样本放哪里

未脱敏的原始日志、采集导出、真机截图和完整轨迹只放在已被 `.gitignore` 忽略的目录：

- `private/`
- `test/fixtures_private/`
- `real_world/`

这些目录如果还不存在，需要时再在本地创建即可，不要提交。

## 合成数据怎么写

优先让人一眼能看出是假的：

- 运单号用低熵或连续数字，例如 `YT0000000000001`、`JT0000000000001`、`YT0012345678901`
- 取件码优先用项目演示码 `3-2-1002`，或脱敏形态 `9-9-9999`、连续数字 `12-3-4567`
- 地点用「示例市」「示例南转运中心」「青柠花园」这类明显虚构名称
- 手机号不要在测试里写连在一起的 11 位真号形态；占位请继续用相邻字符串（如 `'138' '00001111'`）或 `1**********`

如果某个合成标记形态上像真值，又必须保留，把它登记到 `tools/pii_allowlist.txt`，并在测试或注释里写明是自造/示例。

## 提交前检查

```bash
bash tools/check_no_pii.sh
bash tools/test_check_no_pii.sh
```

门禁默认扫描 `test/`、`docs/`、`lib/` 以及根目录说明文档，覆盖运单号、取件码和手机号。命中时只报告路径、行号和规则名，不打印原文。已忽略的真实样本目录不会被扫描。

本约定只约束后续提交。清理历史提交需要单独授权，不能靠再提交覆盖来抹掉旧记录。
