# P45 界面与交互说明

基线 c9b0128 / 1.0.0+12。Flutter 原生动画原则迁移，不引入 SwiftUI/UIKit。

- 卡片保持现有材料、布局、完整取件码。q=0静止、q=1按压；沿用 .975 缩放和 m1/k520/c32，切目标先取q与有符号q/s再停止旧动画。原生 onTap 是唯一详情入口，取消不提交，长按与子按钮沿用。
- 在途列表改 SliverList；每ID独占呈现entry/controller/稳定最外层key。初始全部可读，无首屏交错。数据增删只size+fade，380ms乘剩余距离；重排立即遵循上游次序，不更改滚动引擎。
- 退出立刻禁pointer、semantics、focus及卡片/子按钮动作；同ID退场重入复用状态与当前进度，旧完成回调用generation作废。离屏退出也回收。
- Reduce Motion 中途开启即终态；卡片1倍，活跃列表1/退出移除。关闭不重播；原有业务和触觉不改。
- 不改业务、鉴权、Hive、登录、同步、排序规则、取件手势与共享StaggeredEntrance。
